Pipeline Architecture & Safeguards

Leakage-Free
  • Zero Target Leakage: final_exam_score is strictly excluded from all training and inference feature sets.
  • Numerical Preprocessing: Handled via SimpleImputer(strategy='median') followed by StandardScaler().
  • Categorical Preprocessing: Handled via SimpleImputer(strategy='most_frequent') followed by OneHotEncoder(handle_unknown='ignore').
  • Model Artifact: Serialized using joblib pipeline at models/student_performance_model.pkl.
