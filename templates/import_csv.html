Automatic Normalization & Imputation

The ingestion engine automatically maps columns, converts 10-point scale CGPA into percentages, and imputes missing optional values with robust statistical defaults.

Column Header Requirement Data Type Description & Validation Rules Sample Value
student_id Required String Unique alphanumeric student registration ID. Used as database primary key. ENG2001
name Recommended String Full name of the student for roster display and individualized reports. Aarav Sharma
parent_email Recommended Email Primary guardian contact email for automated early academic alerts. parent.aarav@college.edu
department Recommended String Engineering discipline branch (e.g., Computer Science, IT, ECE, EEE, Mechanical). Computer Science and Engineering
semester Recommended Integer (1 - 8) Current academic semester of study. 5
prev_sem_cgpa Recommended Float (0 - 10) Previous semester CGPA. Automatically multiplied by 9.5 to compute percentage. 8.40
attendance_percentage Optional Float (0 - 100) Cumulative classroom attendance rate across all subjects (default: 75%). 88.5
internal_exam_1 Optional Float (0 - 100) Continuous Assessment Examination 1 marks (default: 65.0). 78.0
internal_exam_2 Optional Float (0 - 100) Continuous Assessment Examination 2 marks (default: 65.0). 82.5
assignment_average Optional Float (0 - 100) Average score obtained across semester course assignments (default: 70.0). 85.0
lab_score Optional Float (0 - 100) Laboratory continuous practical assessment marks (default: 70.0). 80.0
backlogs Optional Integer (≥ 0) Number of current active backlogs / arrear subjects (default: 0). 0
Missing optional fields receive statistical median defaults automatically during ingestion.
